# v0.2 contributor artifacts

Working material from Edge contributors, kept beside the code so the owner can review it.

## Layout

`agents/{role}/{WI-ID}/` — for example `agents/contributor/WI-032/`.

Roles: `contributor`, `researcher`, `architect`.

## Keep

- Short notes, coverage lists, diffs, test output and small redacted screenshots.
- A `README.md` per work item with the brief, what changed and where the result is reviewed.

## Ignore

Builds, `node_modules`, raw recordings and anything holding a credential or personal file. Delete scratch that no longer explains a decision. QA evidence belongs in `qa/`.
