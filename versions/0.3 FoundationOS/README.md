# 0.3 FoundationOS — Accounts and connection

Status: planned product increment.

Start the local v0.3 server, open FoundationOS, and create the first owner or sign in to an existing workspace. Members join by invitation. A valid sign-in survives closing and reopening the browser. Each user can sign out of the current session or all their sessions on this server. Account enrollment and password recovery preserve private homes and preferences.

In Settings → Profile, members can choose an available username, change their password, edit their introduction and optional email, and add, replace or remove their picture. Deleting a member account ends access and takes its private Home offline for 30 days. Recovery is available before the deadline. Permanent cleanup follows expiry.
