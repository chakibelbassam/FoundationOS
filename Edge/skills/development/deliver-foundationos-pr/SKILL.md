# deliver foundationos pr

Read the item and base branch. Create a codex/ branch carrying its ID. Stage only relevant files. Run its acceptance and inspect the staged diff for runtime data and credentials. Push to the configured origin and open one PR citing item ID, observed evidence and remaining limits. Record the PR URL using the current revision. Leave merge and acceptance to the owner.
