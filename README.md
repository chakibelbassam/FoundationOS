# FoundationOS Development

FoundationOS brings software and other artifacts into a workspace where people can find, open and use what they create. The starting example is a Weather app made months ago. Find it, open its folder and run it without remembering the framework or startup command.

Start with the [product definition](planning/FoundationOS.md), the [planning index](planning/README.md), and the [decision log](planning/harness-strategy/01-decision-log.md). The current increment is [0.1 FoundationOS](versions/0.1%20FoundationOS/README.md).

This planning folder is the working home for continuing discussions with OpenCode and other tools. Earlier documents contain ideas and proposals that need review. Use the decision log and current increment to follow the latest direction. Future version briefs belong under versions and link to this shared planning material.
