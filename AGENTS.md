# Work in FoundationOS Development

Read README.md and the selected version brief. Use the project Scrum tool for delivery records. An approved work item is the scope for a branch. Link the ID, acceptance evidence and PR. The owner approves merges.

Verify version behaviour through its launcher before updating the Manual. Use the Vision for intended behaviour and research for open questions. Build interface controls with MUI or React Bits, use Material Icons, and update the interface inventory. Store personal data, credentials and live service state outside this repository.
